# To-Do List App

## Descripción
Aplicación de lista de tareas desarrollada con React,
TypeScript y Vite.

## Tecnologías utilizadas
- React
- TypeScript
- Vite
- HTML y CSS

## Funcionalidades
- Agregar tareas.
- Editar tareas.
- Eliminar tareas.
- Marcar tareas como completadas.
- Filtrar tareas.
- Contador de tareas pendientes.
- Guardado automático con localStorage.

## Custom Hook: useLocalStorage

Se creó un hook personalizado para reutilizar
la lógica de almacenamiento local.

Se utiliza useState para administrar los datos
y useEffect para guardar los cambios en localStorage.

## Instalación

1. Clonar el repositorio.
2. Ejecutar npm install.
3. Ejecutar npm run dev.
